# 현장 일정 날씨판

오늘 현장 일정과 지역별 날씨를 한 화면에서 보고, 날씨 때문에 주의 · 중지를 검토할 일정을 표시합니다. (교육용 가상 데이터)

## 여는 법
- 내 PC : `index.html` 더블클릭
- 인터넷 : (배포 후 Vercel 주소를 여기에 적기)

## Supabase 연결
1. Supabase 프로젝트의 SQL Editor에서 `setup.sql` 전체를 실행합니다. `public.wx_tasks` 표와 가상 일정 6건, 지역·구분 제약, RLS 정책을 만듭니다. 같은 스키마에서 다시 실행해도 기본 일정은 중복 추가하지 않습니다.
2. `config.js`의 두 빈 문자열에 프로젝트 URL과 공개용 publishable 키(`sb_publishable_…`) 또는 기존 anon 키를 넣습니다. secret 키와 service_role 키는 사용하지 않습니다.
3. 페이지를 열거나 새로고침합니다. 인터넷 연결이 필요하며, 더블클릭으로 열어도 Supabase에서 직접 읽습니다.

교육용 공개 표이므로 주소와 공개용 키를 가진 방문자는 가상 일정을 조회·추가할 수 있습니다. 수정·삭제는 허용하지 않습니다. 다른 사람이 추가한 일정은 새로고침하면 보입니다.

현재 일정의 저장소는 Supabase 하나입니다. `data/tasks.json`과 기존 `localStorage.wx_added`는 읽거나 자동 이전하지 않으며, 기존 브라우저 데이터는 삭제하지 않습니다. 설정 누락이나 통신·저장 실패는 화면에 안내합니다.

## 확인 방법
- T-01: 설정 후 가상 일정 6건이 표시되는지 확인합니다.
- T-02: 가상 일정을 추가하고 새로고침하거나 다른 브라우저에서 열어도 보이는지 확인합니다.
- T-03: 지역별 날씨와 판단이 표시되는지 확인합니다.
- T-04: `?test=wind`를 붙여 고소 일정이 중지 검토로 바뀌는지 확인합니다.
- T-06: '오늘판단md로저장'을 눌러 파일명 날짜, 현재 표, 마지막 판단 기준을 확인합니다.
- T-07: SQL Editor에서 아래 문장을 **각각** 실행하면 CHECK 제약 오류가 발생해야 합니다. 실패한 행은 저장되지 않습니다.

```sql
-- 잘못된 지역
insert into public.wx_tasks (title, region, kind, owner)
values ('가상 제약 시험', '서울', '야외', '가상담당');

-- 잘못된 구분
insert into public.wx_tasks (title, region, kind, owner)
values ('가상 제약 시험', '세종', '기타', '가상담당');
```

공개 키만으로 조회·추가는 가능하고 수정·삭제는 차단되는지도 확인합니다. 빈 설정·잘못된 설정·네트워크 단절 시 입력 내용이 사라지거나 저장되지 않은 일정이 표에 추가되지 않아야 합니다.
